# Bousai Guide

Bousai Guide is a practical companion for disaster preparedness in Japan, helping people understand local risks, prepare with confidence, and find clear guidance when it matters.

The project started as an interactive hazard map of Japan using official data sources. It aims to grow into a disaster preparedness guide for everyday life—helping people assess a new neighbourhood, prepare an emergency kit, make a family evacuation plan, or understand what to do when an alert arrives.

Contributions are welcome.

## Requirements

- node v22
- npm v10

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```
